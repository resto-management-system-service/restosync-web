**Date:** 2026-08-29

Driven headless with Playwright: list → create → find → edit → delete → categories
list → create category → category-delete guard (409).

## Preconditions

- `.env.local` has `NEXT_PUBLIC_DISABLE_AUTH=true` (Clerk is fully bypassed in dev)
- `pnpm dev` running; the MSW mock backend starts automatically before first render
  (`src/components/mock-gate.tsx`)
- The mock DB is faker-seeded and **re-seeds on every full page load** — created /
  edited / deleted rows live only for the current tab session

## Manual test script

### 1. Menu items — list

1. **Dashboard → Menu → Items** (`/dashboard/menu/items`; `/dashboard/menu` redirects here).
2. ~14 seeded rows: **Name**, **Category** badge (resolved name), **Price** (formatted,
   e.g. `$11.24`), **Status** (Available / Unavailable), row actions.
3. Footer: `N row(s) total`, `Page 1 of 2`, rows-per-page selector.
4. **Search items…** filters by name client-side; **Reset** clears it.
5. **Name** / **Price** column headers → client-side sort.

### 2. Menu items — create

1. **Add Item** → `/dashboard/menu/items/new`, "Create Menu Item".
2. Submitting empty → inline errors ("Item name must be at least 2 characters.",
   "Price must be greater than 0.", "Please select a category.").
3. Fill **Item Name** = `Truffle Arancini`, **Price** = `13.50`, **Category** =
   `Appetizers`, **Currency** stays `USD`, optional **Description**.
4. Submit → toast **"Menu item created"**, back to the list (soft nav).
5. New row appears immediately — price `$13.50` (13.50 → 1350 cents → formatted),
   category `Appetizers`, status `Available`. Total +1.

### 3. Menu items — edit

1. Row **⋮ → Update** → `/dashboard/menu/items/<id>`, "Edit Menu Item", pre-filled
   (price in dollars).
2. Change **Price** to `9.99`, submit → toast **"Menu item updated"**, list shows `$9.99`.

### 4. Menu items — delete

1. Row **⋮ → Delete** → "Are you sure?" dialog.
2. **Continue** → toast **"Menu item deleted"**, row gone immediately, total −1.
   (**Cancel** / **✕** dismisses with no change.)

### 5. Categories — list + create

1. **Dashboard → Menu → Categories** (`/dashboard/menu/categories`).
2. 4 seeded rows (Appetizers / Mains / Desserts / Drinks) with **Sort Order** + **Status**.
3. **Add Category** → **Name** (≥2 chars) + **Sort Order** → submit → toast
   **"Category created"**, new row appears. Edit via **⋮ → Update** works the same way.

### 6. Categories — delete guard (contract 409)

1. Row **⋮ → Delete** on a category that still has items (e.g. **Appetizers**) →
   **Continue** → error toast **"Cannot delete category — Move or remove its menu items
   first."** The category is **not** removed. (Known nit: the confirm dialog stays open
   on error.)
2. Deleting an **empty** category succeeds and removes the row.

### 7. Auth-disabled placeholders

With `NEXT_PUBLIC_DISABLE_AUTH=true`, these render an "unavailable in dev" notice
instead of Clerk UI: `/dashboard/workspaces`, `/dashboard/workspaces/team`,
`/dashboard/billing`, `/dashboard/exclusive`, `/dashboard/profile`, `/auth/sign-in`,
`/auth/sign-up`. The sidebar shows a static "Dev Workspace" / "Dev User".

## Notes (by design)

- Menu data is fetched **only on the client** (`useQuery`) against the browser MSW
  store, so create / update / delete stay consistent with the list. No server prefetch.
- MSW handlers are keyed to the exact API base URL (`src/mocks/api-url.ts`) — a bare
  `*/menu/...` glob also matched Next.js route requests and broke client-side navigation.
- `GET /menu/items` returns a bare array → table pagination is client-side.
- Response shapes come from `src/features/menu/api/types.ts` (OpenAPI types responses
  as `unknown`).
